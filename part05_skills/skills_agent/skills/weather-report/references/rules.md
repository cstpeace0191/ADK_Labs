# 날씨 브리핑 규칙 (도메인 규칙 · 예외 상황 매뉴얼)

## 판단 기준 (scripts/outdoor_rule.py 가 구현)

| 조건 | 야외 활동 |
|---|---|
| 기온 33°C 이상 (폭염) | 불가 |
| 기온 -10°C 이하 (한파) | 불가 |
| 비 · 눈 · 뇌우 | 불가 |
| 흐림 | 주의 |
| 맑음 · 구름 조금 | 가능 |
| 그 밖의 날씨 | 판단 보류 |

## 예외 상황

- 조회 실패(status=error): 날씨를 지어내지 않는다. 템플릿의 "현재"와 "야외 활동"을 모두 "정보 없음"으로 쓴다.
- 폭염·한파로 "불가"가 나오면 템플릿 맨 아래에 안내 한 줄을 덧붙인다: "※ 실내 수업으로 대체합니다."
- 스크립트 실행이 실패하면 판단을 추측하지 말고 "판단 보류"로 쓴다.
