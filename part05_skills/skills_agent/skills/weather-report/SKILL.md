# 날씨 브리핑 스킬 (Weather Report Skill)

도시별 실시간 기상 정보를 바탕으로 야외 활동 적합성을 객관적으로 판정하고, 학교 표준 공지 형식의 브리핑 문서를 생성하는 전문 스킬입니다.

---

## 1. 사용 시점 (When to Use)

- 사용자가 하나 이상의 도시에 대해 날씨 브리핑이나 기상 공지를 요청할 때
- 날씨 기반으로 체육 활동, 야외 수업, 소풍 등의 "야외 활동 가능 여부"를 질의할 때
- 학사 일정 또는 학생 대상 공지문 형식으로 기상 상황 정리를 원할 때

## 2. 사용하지 않는 경우 (When Not to Use)

- 날씨와 무관한 단순 학사 일정 질의나 학생 개인 인사 (`greeting-skill` 사용 권장)
- 과거 기상 통계 데이터 분석이나 장기 예보 예측 질의

---

## 3. 필수 도구 및 리소스 (Prerequisites & Tools)

### 필요 도구
- **`get_weather(city: str)`**: 스킬 활성화 시 동적으로 제공되는 도시별 현재 날씨 조회 도구
- **`run_skill_script`**: 스킬 내 파이썬 스크립트 실행 도구
- **`load_skill_resource`**: 스킬 리소스(템플릿, 규칙 문서) 로드 도구

### 스킬 리소스 구성
- `scripts/outdoor_rule.py`: 결정론적(Deterministic) 야외 활동 적합성 판정 스크립트
- `references/rules.md`: 판정 기준표 및 폭염·한파·조회 실패 대응 매뉴얼
- `assets/briefing_template.md`: 학교 표준 날씨 브리핑 출력 템플릿

---

## 4. 단계별 실행 절차 (Workflow / Instructions)

요청받은 모든 도시에 대해 아래의 4단계를 순서대로 엄격히 수행합니다.

### 1단계: 날씨 정보 조회 (Weather Data Fetch)
- 사용자가 질의한 각 도시를 인자로 `get_weather(city="<도시명>")`를 호출합니다.
- 응답 형태:
  - 성공: `{"status": "success", "city": "<도시>", "report": "<날씨>, <기온°C>"}`
  - 실패: `{"status": "error", "error_message": "<도시> 정보 없음"}`

### 2단계: 야외 활동 판단 스크립트 실행 (Run Script)
- 날씨 조회에 성공한 도시마다 `run_skill_script` 도구로 `scripts/outdoor_rule.py`를 실행합니다.
- **인자(args) 전달 형식**:
  ```json
  {
    "condition": "<날씨 상태>",
    "temp": "<기온 숫자>"
  }
  ```
  *(예: 맑음, 18°C인 경우 `{"condition": "맑음", "temp": "18"}`)*
- **주의**: 야외 활동 가능 여부(가능/주의/불가)를 에이전트가 임의로 추측하지 말고 반드시 스크립트의 실행 결과(`verdict`, `reason`)를 그대로 인용합니다.

### 3단계: 도메인 매뉴얼 및 예외 규칙 확인 (Check Rules)
- `load_skill_resource` 도구로 `references/rules.md`를 불러와 다음 예외 상황을 확인하고 반영합니다:
  - **조회 실패 (`status=error`)**: 날씨를 지어내지 않고, 템플릿의 '현재'와 '야외 활동' 항목을 모두 "정보 없음"으로 기재합니다.
  - **폭염(33°C 이상) 또는 한파(-10°C 이하)**: 스크립트 결과가 "불가"일 경우, 해당 도시 브리핑 블록 맨 하단에 다음 문구를 반드시 추가합니다:
    ```text
    ※ 실내 수업으로 대체합니다.
    ```
  - **스크립트 실행 오류**: 스크립트 실행 실패 시 자의적 판단을 배제하고 "판단 보류"로 기록합니다.

### 4단계: 표준 템플릿 작성 및 최종 출력 (Format Output)
- `load_skill_resource` 도구로 `assets/briefing_template.md`를 읽어옵니다.
- 도시별로 템플릿 구조를 동일하게 채워 최종 답변을 작성합니다:
  ```text
  [날씨 브리핑] <도시>
  - 현재: <날씨>, <기온>
  - 야외 활동: <가능 | 주의 | 불가 | 판단 보류> (<판단 이유>)
  ```

---

## 5. 출력 형식 및 예시 (Output Examples)

### 예시 1: 정상 기상 (가능 / 주의)
```text
[날씨 브리핑] 서울
- 현재: 맑음, 18°C
- 야외 활동: 가능 (맑음)
```

### 예시 2: 악천후 및 극한 기온 (폭염 안내 문구 포함)
```text
[날씨 브리핑] 제주
- 현재: 비, 16°C
- 야외 활동: 불가 (강수(비))

[날씨 브리핑] 대구
- 현재: 맑음, 35°C
- 야외 활동: 불가 (폭염(33°C 이상))
※ 실내 수업으로 대체합니다.
```

### 예시 3: 정보 미등록 도시 (조회 실패)
```text
[날씨 브리핑] 광주
- 현재: 정보 없음, 정보 없음
- 야외 활동: 정보 없음 (광주 정보 없음)
```

---

## 6. 품질 및 안전 가이드라인 (Guidelines)

1. **결정론적 판정 준수**: 야외 활동 적합성은 감각이나 언어 모델의 확률적 생성에 의존하지 않고, 항상 `scripts/outdoor_rule.py`의 결과와 `references/rules.md` 지침만을 따릅니다.
2. **환각(Hallucination) 방지**: 날씨 정보가 없거나 도구 호출이 실패한 경우 임의의 기온이나 날씨를 유추하거나 생성하지 않습니다.
3. **일관된 템플릿 구조**: 여러 도시를 동시에 보고할 때도 각 도시마다 표준 템플릿 블록을 빠짐없이 유지합니다.
