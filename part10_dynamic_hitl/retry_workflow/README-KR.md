# retry_workflow — 일시적 오류 자동 재시도 워크플로우

일시적인 네트워크 단절(`ConnectionError`)이나 외부 API 지연 시 설정된 정책에 따라 자동으로 재시도하여 시스템 복원력을 높이는 패턴입니다.

---

## 1. 동작 구조

- **엔트리포인트**: `agent.py`의 `root_agent`
- **시뮬레이션 시나리오**:
  - `weather_api`: 1회차, 2회차 호출 시 고의로 `ConnectionError("일시적 네트워크 오류")`를 발생시킴
  - 워크플로우 노드 러너가 예외를 감지하고 설정된 재시도 간격(백오프) 후 3회차 재호출
  - 3회차에 정상 응답(`부산: 맑음 18°C`)을 수신하여 작업 성공 완료
