# feedback_workflow — 인터랙티브 피드백 반영 워크플로우

사용자에게 복수의 후보(추천 여행 일정 등)와 메타데이터 payload를 제시하고, 사용자가 선택한 항목과 주관식 코멘트를 반영하여 최종 결과물을 재조정하는 HITL 패턴입니다.

---

## 1. 동작 구조

- **엔트리포인트**: `agent.py`의 `root_agent`
- **실행 흐름**:
  1. 도시(예: "서울") 입력 시 추천 활동 4개 생성
  2. `payload={'city': '서울', 'activities': [...]}`와 함께 사용자 피드백 요청 대기
  3. 사용자가 `{'liked': ['고궁 산책', '한강 자전거'], 'comment': '오전 위주로'}` 전송
  4. 다음 노드가 사용자의 피드백을 수용하여 최종 맞춤 일정을 확정 출력

---
