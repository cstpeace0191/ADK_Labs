# approval_gate — 고위험 결재 게이트 및 감사(Audit) 워크플로우

환불, 송금, 데이터 삭제 등 위험도가 높은 작업 실행 전에 책임자의 승인을 요구하고 모든 결정 이력을 감사 로그로 남기는 엔터프라이즈 HITL 패턴입니다.

---

## 1. 동작 구조

- **엔트리포인트**: `agent.py`의 `root_agent`
- **실행 흐름**:
  1. 주문 번호 `ORD-777` 및 결제 금액(`450,000원`), 정책 플래그(`개봉 상품`)를 포함한 결재 요청 생성
  2. 승인 게이트(`RequestInput`)에서 멈춤
  3. 관리자의 응답:
     - `{'approve': True, 'note': '단골 고객'}` → 환불 실행 및 감사 로그 기록
     - `{'approve': False, 'note': '정책 위반'}` → 환불 거절 및 사유 기록
  4. 세션 감사 로그(`audit_log`)에 결정 시간, 승인 여부, 사유가 영구 기록됨
