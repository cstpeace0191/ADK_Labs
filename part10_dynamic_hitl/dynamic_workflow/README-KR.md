# dynamic_workflow — 런타임 동적 노드 생성 워크플로우

고정된 그래프 정의 대신, 런타임에 처리해야 할 데이터나 단계 수에 따라 동적으로 노드를 생성하여 실행하는 패턴입니다.

---

## 1. 동작 구조

- **엔트리포인트**: `agent.py`의 `root_agent`
- **실행 원리**:
  - 사용자 입력에 따라 필요한 연산 단계(예: `x^2`, `x+1` 등)를 런타임에 동적으로 인스턴스화하고 순차 파이프라인으로 연결하여 최종 결과를 계산합니다.

---

## 2. 실행 방법

🟢 **LLM 키 없이 실행 가능합니다.**

```bash
cd part10_dynamic_hitl
uv run run_part10.py
```
