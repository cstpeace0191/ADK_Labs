# refund_workflow — 실무 사례 ①: 주문 환불 자동화 워크플로우

전자상거래 서비스의 주문 유효성 검증, 결제 수단별 환불 API 호출, 고객 맞춤형 안내문 생성을 결합한 실무 워크플로우입니다.

---

## 1. 비즈니스 흐름

1. **주문 조회 (`fetch_order`)**: 주문 번호로 결제 상태 및 금액 조회
2. **정책 검증 (`check_policy`)**: 구매 후 30일 이내 여부 판단
3. **금액 분기 (`route_by_amount`)**:
   - 10만 원 이하: 자동 즉시 환불 처리
   - 10만 원 초과: 관리자 수동 승인 큐 등록
4. **결과 통보 (`format_notice`)**: 사용자에게 친절한 결과 안내 메시지 발행

---

cd part09_graph_workflow
