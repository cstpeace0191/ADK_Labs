# Google ADK `Event` Object Structure and Role Guide

This document is a comprehensive guide to the **`Event` object**, which is the streaming element returned when executing `runner.run_async()` or `runner.run()`, as seen in `direct-adk-simple-async.py`.

In Google ADK, an `Event` represents the fundamental unit of conversation history and state transition occurring throughout an agent's execution lifecycle. It is also the data model persisted in session storage (`session.events`). Internally, it extends `LlmResponse` (model response) with execution and context metadata.

---

## 1. Key Fields (google-adk)

### ① Identification & Trace Metadata (Event-Specific Fields)
| Field Name | Type | Description and Role |
| :--- | :--- | :--- |
| `id` | `str` | Unique event identifier (UUID) |
| `invocation_id` | `str` | Execution ID for a single turn (user request). Multiple events generated during a single request share the same `invocation_id` |
| `author` | `str` | The entity that created the event (`"user"` or agent name, e.g., `"memory_assistant"`) |
| `timestamp` | `float` | Creation time of the event (Unix epoch in seconds) |
| `branch` | `str \| None` | Hierarchical path in multi-agent or sub-agent execution (e.g., `"root.sub"`) |

### ② Message Content: `content` (`types.Content`)
The core payload containing the model's output or the user's input.
- **`content.role`**: `"model"` or `"user"`
- **`content.parts`**: List of `types.Part` objects. Each Part contains one of the following:
  - `part.text`: Standard textual response generated by the model
  - `part.function_call`: Tool invocation request emitted by the model (function name and arguments)
  - `part.function_response`: Local tool execution result (function name and return value)
  - `part.thought = True`: Model reasoning/thought process (when Gemini Thinking or Planner is enabled)

### ③ State & Control Side Effects: `actions` (`EventActions`)
Changes made to the session or workflow control flow as a result of the event.
| Field Name | Description |
| :--- | :--- |
| `state_delta` | Session State dictionary updated or added in this event (`output_key` storage or state mutations within tools) |
| `artifact_delta` | Created or modified artifacts (files, binary data, etc.) |
| `transfer_to_agent` | Name of the target sub-agent when transferring control |
| `escalate` | Escalation signal to terminate a loop or return control to a parent agent |
| `requested_tool_confirmations` | Human-in-the-Loop (HITL) approval requests awaiting user confirmation |
| `end_of_agent` | Flag indicating that the current agent's execution is complete |

### ④ Model Response Details (Inherited from `LlmResponse`)
| Field Name | Description |
| :--- | :--- |
| `partial` | Indicates whether this is an intermediate streaming chunk (always `True` for incremental chunks in SSE streaming mode) |
| `turn_complete` | Indicates whether the current turn has completed |
| `finish_reason` | Reason generation ended (`"STOP"`, `"MAX_TOKENS"`, `"SAFETY"`, etc.) |
| `usage_metadata` | Token usage details (`prompt_token_count`, `candidates_token_count`, `total_token_count`) |
| `model_version` | Exact version of the model used for the invocation |
| `grounding_metadata` / `citation_metadata` | Search grounding metadata or citation source information |

## 2. Frequently Used Helper Methods

- **`event.is_final_response()` (`bool`)**:
  - Determines whether the event contains the final text response intended for the user.
  - Returns `True` if it is neither a tool call (`function_call`) nor a tool result (`function_response`), and not an intermediate streaming chunk (`partial=True`).
- **`event.get_function_calls()`**:
  - Extracts only the tool call requests (`function_call`) from the event.
- **`event.get_function_responses()`**:
  - Extracts only the tool execution results (`function_response`) from the event.

## 3. Event Emission Patterns by Agent Type

### Pattern A: Simple LLM Agent without Tools (`direct-adk-simple-async.py`)
Because there are no tool calls, **only a single event** containing the model's generated text is returned.
```text
Event(
  author='memory_assistant',
  content=Content(role='model', parts=[Part(text='The sky is blue because of Rayleigh scattering...')]),
  partial=False,
  finish_reason='STOP',
  usage_metadata=UsageMetadata(prompt_token_count=..., total_token_count=...),
  actions=EventActions(state_delta={})
)
=> is_final_response() == True
```

### Pattern B: Tool-Calling Agent
Events are emitted sequentially across multiple steps: tool call request, tool result, and final text response.
```text
① [Event 1] author='agent', function_call('get_weather', {'city': 'Seoul'})
   => is_final_response() == False
② [Event 2] author='agent', function_response('get_weather', {'temp': 18, 'condition': 'Clear'})
   => is_final_response() == False
③ [Event 3] author='agent', text("The current weather in Seoul is clear with a temperature of 18°C.")
   => is_final_response() == True
```

## 4. Event Monitoring Code Example

Calling `print(event)` directly dumps extensive internal attributes. Filtering for key details as shown below is recommended:

```python
async for event in runner.run_async(
    user_id=user_id,
    session_id=session1.id,
    new_message=user_message
):
    kinds = []
    if event.content and event.content.parts:
        for p in event.content.parts:
            if p.text:
                kinds.append(f"text({len(p.text)} chars)")
            if p.function_call:
                kinds.append(f"call:{p.function_call.name}")
            if p.function_response:
                kinds.append(f"result:{p.function_response.name}")
            if getattr(p, "thought", False):
                kinds.append("thought")
                
    tokens = event.usage_metadata.total_token_count if event.usage_metadata else "-"
    print(f"[{event.author}] {kinds} | Final={event.is_final_response()} | StateDelta={event.actions.state_delta} | Tokens={tokens}")

    if event.is_final_response():
        if event.content and event.content.parts:
            final_text = "".join(p.text for p in event.content.parts if hasattr(p, "text") and p.text)
            print("Final Response:\n", final_text)
```
