# step1_basic — 1단계: 기본 학사 안내 에이전트

도구 연동 없이 학사 안내 일반 규정 지시문만을 가진 가장 기본적인 단일 LLM 에이전트 단계입니다.

---

## 1. 동작 구조

- **엔트리포인트**: `agent.py`의 `root_agent`
- **역할**: 도서관 운영 시간, 휴학/복학 신청 기간 등 일반 학사 규정을 안내합니다.

---

## 2. 실행 방법

`part14_lab` 폴더에서 실행합니다 (🔑 Gemini 키 필요):

```bash
cd part14_lab
uv run run_lab.py 1
```
