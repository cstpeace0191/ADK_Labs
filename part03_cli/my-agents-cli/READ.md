# my-agents-cli

Simple ReAct agent
Agent generated with `agents-cli` version `1.13.0`

## Project Structure

The project contains files scaffolded initially by `agents-cli create` as well as files and directories generated dynamically at runtime or by enhancement commands.

```text
my-agents-cli/
├── app/                              # [Static] Core agent application code
│   ├── agent.py                      # [Static] Main agent logic (root_agent definition, tools, instructions)
│   ├── fast_api_app.py               # [Static] FastAPI backend server exposing agent endpoints
│   ├── __init__.py                   # [Static] Application package entry point
│   ├── app_utils/                    # [Static] Helper utilities
│   │   ├── a2a.py                    # [Static] A2A (Agent-to-Agent) protocol card & utilities
│   │   ├── reasoning_engine.py       # [Static] Vertex AI reasoning engine integration
│   │   └── services.py               # [Static] Session and memory service initializers
│   └── .adk/                         # ⚡ [Dynamic - Runtime] Created at runtime by ADK / Playground
│       └── session.db                # ⚡ [Dynamic - Runtime] Local SQLite database storing conversation sessions & state
├── tests/                            # [Static] Test suites
│   ├── unit/                         # [Static] Unit tests (e.g. test_dummy.py)
│   ├── integration/                  # [Static] E2E integration tests (test_server_e2e.py, test_agent_card.py)
│   └── eval/                         # [Static] Agent evaluation suite
│       ├── datasets/                 # [Static] Evaluation dataset definitions (e.g. basic-dataset.json)
│       ├── eval_config.yaml          # [Static] Evaluation metrics and criteria configuration
│       └── response_quality.py       # [Static] Response quality evaluator logic
├── deployment/                       # 🛠️ [Dynamic - Command] Generated by `agents-cli scaffold enhance`
│   └── terraform/                    # 🛠️ [Dynamic - Command] Terraform IaC modules for GCP cloud infrastructure
├── .google-agents-cli/               # ⚡ [Dynamic - Runtime] Created at runtime by agents-cli CLI
│   └── run_state.json                # ⚡ [Dynamic - Runtime] Local command execution state and cache
├── .venv/                            # ⚡ [Dynamic - Setup] Python virtual environment created by `agents-cli install` / `uv`
├── uv.lock                           # ⚡ [Dynamic - Setup] Dependency lockfile generated/updated by uv
├── deployment_metadata.json          # 🛠️ [Dynamic - Command] Metadata generated during build/deployment stages
├── .env                              # ⚙️ [User / Config] Local environment variables (copied from .env.example)
├── .env.example                      # [Static] Environment variable template
├── .gcloudignore                     # [Static] File exclusion list for GCP deployment packaging
├── .gitignore                        # [Static] Git exclusion list
├── agents-cli-manifest.yaml          # [Static] Project manifest (base template, agent runtime configuration)
├── Dockerfile                        # [Static] Container build definition for Cloud Run / Agent Runtime
├── GEMINI.md                         # [Static] AI-assisted development context guide for Antigravity
├── pyproject.toml                    # [Static] Project configuration and dependencies (uv package manager)
├── README.md (READ.md)               # [Static] English project documentation
└── README-KR.md (READ-KR.md)         # ✍️ [Documentation] Korean project documentation
```

### Legend
- **`[Static]`**: Scaffolded initially during project creation (`agents-cli create`).
- **`⚡ [Dynamic - Runtime]`**: Automatically generated during execution (`agents-cli playground`, `uv run adk web`, test runs).
- **`⚡ [Dynamic - Setup]`**: Automatically created/resolved when installing dependencies (`agents-cli install` / `uv sync`).
- **`🛠️ [Dynamic - Command]`**: Generated dynamically when running enhancement/infra commands (`agents-cli scaffold enhance`, `agents-cli infra`).
- **`⚙️ [User / Config]`**: Configured or copied by the developer.

> 💡 **Tip:** Use [Antigravity CLI](https://antigravity.google/) for AI-assisted development - project context is pre-configured in `GEMINI.md`.

## Requirements

Before you begin, ensure you have:
- **uv**: Python package manager (used for all dependency management in this project) - [Install](https://docs.astral.sh/uv/getting-started/installation/) ([add packages](https://docs.astral.sh/uv/concepts/dependencies/) with `uv add <package>`)
- **agents-cli**: Agents CLI - Install with `uv tool install google-agents-cli`
- **Google Cloud SDK**: For GCP services - [Install](https://cloud.google.com/sdk/docs/install)


## Quick Start

Install `agents-cli` and its skills if not already installed:

```bash
uvx google-agents-cli setup
```

Install required packages:

```bash
agents-cli install
```

Test the agent with a local web server:

```bash
agents-cli playground
```

You can also use features from the [ADK](https://adk.dev/) CLI with `adk`.

## Commands

| Command              | Description                                                                                 |
| -------------------- | ------------------------------------------------------------------------------------------- |
| `agents-cli install` | Install dependencies using uv                                                         |
| `agents-cli playground` | Launch local development environment                                                  |
| `agents-cli lint`    | Run code quality checks                                                               |
| `agents-cli eval`    | Evaluate agent behavior (generate, grade, analyze, and more — see `agents-cli eval --help`) |
| `uv run pytest tests/unit tests/integration` | Run unit and integration tests                                                        |
| `agents-cli deploy`  | Deploy agent to Agent Runtime                                                                |
| `agents-cli publish gemini` | Register deployed agent with Gemini                                    |
| [A2A Inspector](https://github.com/a2aproject/a2a-inspector) | Launch A2A Protocol Inspector                                                        |

## 🛠️ Project Management

| Command | What It Does |
|---------|--------------|
| `agents-cli scaffold enhance` | Add CI/CD pipelines and Terraform infrastructure |
| `agents-cli infra cicd` | One-command setup of entire CI/CD pipeline + infrastructure |
| `agents-cli scaffold upgrade` | Auto-upgrade to latest version while preserving customizations |

## Development

Edit your agent logic in `app/agent.py` and test with `agents-cli playground` - it auto-reloads on save.

## Deployment

```bash
gcloud config set project <your-project-id>
agents-cli deploy
```

To add CI/CD and Terraform, run `agents-cli scaffold enhance`.
To set up your production infrastructure, run `agents-cli infra cicd`.
