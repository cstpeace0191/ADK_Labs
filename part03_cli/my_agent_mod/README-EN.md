# my_agent_mod — ADK CLI Basic Weather Agent

This project is a weather lookup agent implemented by extending the standard agent scaffold generated by `adk create my_agent_mod` with a custom tool (`get_weather`). When answering user inquiries, the conversational model calls the tool function (Function Calling) to deliver accurate information when asked about the weather of specific cities.

---

## 1. Directory Structure

```text
my_agent_mod/
├── agent.py          # 📄 [Core Code] Implements get_weather tool and weather_agent (root_agent)

    └── session.db    # ⚡ [Dynamically Generated] Local SQLite database storing conversation sessions
```

### Key Files and Roles
- **`agent.py`**: Defines the `get_weather(city: str) -> dict` function and registers it with `tools=[get_weather]` inside `weather_agent` (`root_agent`).
- **`__init__.py`**: Exposes the agent module via `from . import agent` so the ADK loader can discover it.
- **`.adk/session.db`**: Local SQLite database automatically created to record session history across CLI runs.

---

## 2. Operation Structure

- **Entry Point**: `root_agent` in `agent.py`
- **Role**: Queries weather for cities such as Seoul and Busan and returns a concise single-sentence response; other questions are answered using general knowledge.
- **Tool (`get_weather`)**:
  ```python
  def get_weather(city: str) -> dict:
      """Returns current weather for a specified city."""
      data = {"서울": "맑음, 18°C", "부산": "흐림, 20°C"}
      if city in data:
          return {"status": "success", "report": data[city]}
      return {"status": "error", "error_message": f"No data for {city}"}
  ```

## 3. How to Run

Run `my_agent_mod` from the parent directory (`part03_cli`) using ADK CLI commands:

```bash
# 1. Navigate to parent directory (if not already there)
cd part03_cli

# 2. Run terminal interactive REPL
adk run my_agent_mod

# 3. Run with in-memory session (no session.db created/used)
adk run --in_memory my_agent_mod

# 4. Run and save session to a file (creates my_agent_mod/s1.session.json upon exit)
adk run --save_session --session_id s1 my_agent_mod

# 5. Resume from a saved session file
adk run --resume my_agent_mod/s1.session.json my_agent_mod

# 6. Launch web UI (open http://localhost:8000 in your browser)
adk web --port 8000

# 7. Launch headless REST / SSE API server
adk api_server --port 8000
```
